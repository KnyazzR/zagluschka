## ✨ Особенности

- 🎨 **Стильный дизайн** — чистый белый фон с фирменными оранжевыми акцентами
- 🔐 **Безопасность по умолчанию** — список пользователей никогда не покидает сервер
- 🛡️ **Защита от брутфорса** — лимит 5 попыток в минуту с одного IP
- ⏱️ **Защита от timing-атак** — постоянное время ответа + `secrets.compare_digest`
- 🍪 **Умные cookie** — автоматический редирект при повторном посещении
- 🐳 **Docker-ready** — запуск одной командой
- 🔄 **Горячая перезагрузка** — обновление списка без пересборки контейнера
- 📦 **Чистая архитектура** — разделённые HTML/CSS/Python слои

## 🚀 Быстрый старт

### 1. Клонируйте проект

```bash
git clone <your-repo-url>
cd zagluschk
```

### 2. Настройте список пользователей

Откройте `docker-compose.yml` и отредактируйте переменную `USERS`:

```yaml
environment:
  USERS: >
    {
      "п": "/dashboard",
      "майкл джексон": "/vip-zone",
      "ivan_petrov": "/client/ivan",
      "company_x": "/partner/x"
    }
```

> Формат: `{"код_доступа": "путь_редиректа"}`. Ключи регистронезависимы.

### 3. Запустите

```bash
docker-compose up -d --build
```

### 4. Откройте в браузере

👉 **http://localhost:8080**

## ⚙️ Конфигурация

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `USERS` | JSON-объект с парами `id → location` | `{}` |
| `PORT` | Порт внутри контейнера | `8000` |

### Примеры форматов `USERS`

**Минимальный:**
```json
{"admin": "/admin", "user1": "/home"}
```

**С кириллицей:**
```json
{"п": "/secret", "клиент_№42": "/client/42"}
```

## 🔌 API Endpoints

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/` | Главная страница (форма входа) |
| `GET` | `/style.css` | Файл стилей |
| `POST` | `/api/check` | Проверка кода доступа |
| `POST` | `/api/reload` | Горячая перезагрузка списка |

### Пример запроса

```bash
curl -X POST http://localhost:8080/api/check \
  -H "Content-Type: application/json" \
  -d '{"input": "п"}'
```

**Ответ (успех):**
```json
{ "redirect": "/dashboard" }
```

**Ответ (ошибка):**
```json
{ "detail": "Неверный код доступа" }
```

## 🔄 Обновление списка пользователей

### Способ 1 — Через `docker-compose.yml` (рекомендуется)

1. Отредактируйте `USERS` в `docker-compose.yml`
2. Перезапустите контейнер:
   ```bash
   docker-compose up -d
   ```

### Способ 2 — Без перезапуска (через API)

```bash
curl -X POST http://localhost:8080/api/reload
```

## 🛡️ Безопасность

### Что уже реализовано

| Угроза | Защита |
|--------|--------|
| 💉 Утечка списка клиентов | Данные только в памяти сервера |
| 🔁 Брутфорс | Rate limit: 5 попыток / мин / IP |
| ⏱️ Timing-атаки | `secrets.compare_digest` + задержка 50мс |
| 🌐 CSRF | Cookie с `SameSite=Lax` |
| 📡 XSS | Нет отражения ввода в HTML |

### 🔧 Рекомендации для продакшена

- [ ] Подключить **HTTPS** через Nginx + Let's Encrypt
- [ ] Установить `secure=True` в `set_cookie()` (main.py)
- [ ] Добавить логирование неудачных попыток
- [ ] Настроить внешний rate-limiter (например, `slowapi`)
- [ ] Хранить хэши ID вместо открытых строк
- [ ] Добавить CORS-политики при необходимости
